# Sakura - Landing Page for Garden Design Studio

![Built with React](https://img.shields.io/badge/React-18.2-%2361DAFB?logo=react) ![TypeScript](https://img.shields.io/badge/TypeScript-5.0-%233178C6?logo=typescript) ![Vite](https://img.shields.io/badge/Vite-Bundler-%23646CFF?logo=vite) ![MUI](https://img.shields.io/badge/Material%20UI-5.14-%23007FFF?logo=mui) ![SCSS](https://img.shields.io/badge/SCSS-Styling-%23CC6699?logo=sass)

A professional and elegant landing page for the "Sakura" landscape design studio, specializing in garden design and landscaping services. The website is designed to attract new clients through a prominent promotion: **"Free specialist consultation until February 28th"**.

**[🚀 View Live Demo](https://aivanii.github.io/AivaniiSakura/)**

![Preview of the Sakura Landing Page](https://i.ibb.co/NdHTqckd/250904-20h16m22s-screenshot.png)

## 🚀 Key Features

*   **Modern & Responsive Design:** Fully adaptive layout that looks perfect on all devices, from mobile phones to desktops.
*   **High Performance:** Achieves Lighthouse scores >90 through optimized images and efficient code.
*   **Strong Call-to-Action (CTA):** Clear and prominent highlighting of the main promotion to drive user engagement.
*   **Conversion-Optimized:** Thoughtful structure and user experience (UX) designed to maximize lead generation and contact form submissions.
*   **Accessibility (a11y):** Built with semantic HTML and best practices for accessibility in mind.

## 🛠️ Tech Stack

*   **Framework:** [React](https://reactjs.org/)
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Component Library:** [Material UI (MUI)](https://mui.com/)
*   **Styling:** [SCSS/SASS](https://sass-lang.com/) for custom styles
